1. Introducción
Buenos días, hoy voy a presentar nuestro proyecto llamado “Lista de Tareas”, una aplicación web sencilla desarrollada en JavaScript, HTML y CSS.

El objetivo principal es permitir al usuario gestionar sus tareas diarias, pudiendo añadir, marcar como completadas o eliminarlas, y ver el porcentaje total de progreso.

2. Funcionalidad principal
La aplicación funciona de una forma muy simple:
	-Se escribe una tarea en el campo de texto y se pulsa “Agregar”.
	-La tarea aparece en la lista como pendiente.
	-Se puede marcar como hecha o eliminar.
	-Automáticamente se actualiza el porcentaje de tareas completadas y una barra de 	progreso verde muestra el avance.

Todo esto se hace sin recargar la página, gracias al uso de JavaScript y manipulación del DOM.

3. Código y aspectos técnicos
El código está dividido en varias funciones:
	-addTask() para añadir una tarea.
	-deleteTask() para eliminarla.
	-toggleTask() para marcarla como completada o pendiente.
	-updateStats() para calcular el porcentaje de progreso.
Se han usado variables let y const, operadores lógicos, condicionales if y bucles forEach.
También se emplea Math.round() para redondear el porcentaje.
Todo el código está comentado en español para facilitar su comprensión.

4. Diseño visual
En cuanto al diseño, se ha elegido un estilo limpio y fácil de leer:
	-Verde para tareas completadas.
	-Rojo para tareas pendientes.
	-Fondo claro y tipografía Arial para mejorar la legibilidad.
Además, la página es responsiva, por lo que se adapta bien a móviles y ordenadores.

5. Organización del trabajo
El proyecto se desarrolló en varias fases:
	1.Creación de la estructura HTML.
	2.Programación en JavaScript.
	3.Aplicación de estilos CSS.
	4.Pruebas y documentación.
También se utilizó GitHub para el control de versiones y, Jira para organizar las tareas.

6. Conclusión
En resumen, este proyecto ha permitido aplicar los fundamentos de la programación en JavaScript, comprender mejor la manipulación del DOM y practicar el diseño web.

Aunque es una aplicación sencilla, demuestra cómo con pocos recursos se puede crear algo útil, interactivo y visualmente claro.
